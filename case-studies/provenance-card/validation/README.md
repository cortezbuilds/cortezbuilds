# Captured card build · controlled subprocess boundary

The parallel local LLM flow capture design calls for evidence at a boundary the observer actually controls. This case study uses `trace_build.py` as a narrow metadata-only observer. The six [saved receipts](receipts/) record a clean-directory desktop SVG build, phone SVG build, both verifiers, the card tests, and the two PNG preview renders. Each receipt records the declared input and output byte hashes and lengths, executable hash, stdout/stderr hashes and lengths, exact command, UTC and monotonic times, exit result, and completeness. The SVGs, JSON receipts, and PNG previews in the parent directory match the traced outputs.

Run `python3 validation/check_receipts.py` from the card directory to compare every saved receipt with the reviewed files and its [command spec](.). Each spec declares the tracer source as an input, binding its exact bytes to the capture. The three build steps record that their outputs were absent before the command. Twenty synthetic tracer tests run with `python3 -m unittest discover -s validation -p test_trace_build.py -v`; sixteen mutation tests exercise the saved-receipt checker with `python3 -m unittest discover -s validation -p test_check_receipts.py -v`. The [pull request workflow](../../../.github/workflows/validate-provenance-card.yml) runs these checks with read-only repository permission.

This evidence is **unsigned local consistency**. The receipts are committed for inspection; they have no independently held checkpoint or trusted timestamp. On Linux, the observer waits for the leader without reaping it, then checks or terminates live members of the same process group before final snapshots. A child that starts a new session or process group escapes that boundary. The observer sees declared file snapshots and one subprocess's standard streams, not every file read, browser child process, network request, model message, or human edit. The PNG render step records the wrapper command and output files; it does not instrument Firefox internally. This trace also does not prove that Codex loaded or followed a skill. The earlier plaintext ledger from the parallel pilot was restricted to synthetic data and was not used on the beliefs draft or a real conversation. The beliefs prose was edited before this capture; its authoring event stream is not reconstructed here.

The public [manifest](../manifest.json) carries the historical incident claims and their evidence classes. The build trace answers a different question: which file bytes were presented to a controlled local build and which output bytes were observed. Neither record alone establishes authorship or current GitHub deployment state.
